# 项目

项目、任务与工时：任务排在甘特上，进度和工时从任务汇总。

- 项目：可选客户（往来单位），计划中 → 进行中 ⇄ 暂停 → 已完成 / 已取消；还有未完成任务时不能完成。进度、实际与计费工时都是汇总。
- 任务：开始、结束、“在…之后”的前置任务与里程碑，默认甘特，可切看板（按阶段）；到期进负责人收件箱，逾期提醒。
- 工时：谁、哪天、哪个任务、几小时、活动类型、是否计费；一天不超过 24 小时。
- 仪表盘：进行中的项目、未完成任务、已记与计费工时，各项目、各成员、各活动的工时，每月工时。
- 角色：`member` 读全部项目、本单元同事的任务、自己的工时；`manager` 读全部、管项目与设置。

设计与取舍见 [DESIGN.md](DESIGN.md)。这是参考 ERPNext projects、OpenProject、Plane、Kimai 等产品的业务思路重新设计的包，不含它们的代码与定义，以 Apache-2.0 发布。

## 安装之后

1. 在“管理 → 成员”给项目经理授予 `manager`，给其余成员授予 `member`；成员按组织单元分组，同一单元的人互相看得到任务。
2. 经理在“设置”里按自己的流程改任务阶段、项目类型与活动类型。
3. 依赖往来单位（`party`）：客户在往来单位里建一次，项目、CRM、售后共用。
