# uom：计量单位

各应用计数、称重与度量所用的单位，库存、采购、生产与工时共用一份。

| 对象 | 是什么 |
|---|---|
| `uom.dimension` 量纲 | 数量、质量、长度、面积、体积、时间 |
| `uom.unit` 单位 | 名称、符号（唯一）、量纲、折合基准单位的系数、取整步长；随包带 27 个，含斤、亩 |

换算：同一量纲内，`数量 × 本单位系数 ÷ 目标单位系数`。基准单位取各量纲里最小的常用单位（克、毫米、平方厘米、毫升、秒），
所以随包的系数都是精确值，只有亩是近似（1 亩 = 2000/3 平方米）。

所有成员能读；`uom: steward` 增改单位与量纲。应用写 `requires: [uom@^0.1.0]`，字段 `{type: reference, ref: uom.unit}`。
