# phone

应用包：经平台语音网关的来电与外呼，在浏览器里接听和拨打，通话记录对上往来单位的联系人。

- 对象 `phone.call`：一通来电或外呼。号码、关于哪条记录（`reference`）在新建时写；方向、坐席、开始时间由新建事务盖上；
  线路、联系人、往来单位、接通时间、时长、未接原因、失败原因只由动作写。状态：振铃中 → 通话中 → 已完成，或未接、失败。
- 角色：`agent` 坐席（看全部、拨打、写备注）、`supervisor` 主管（另可归档）、`gateway` 语音网关的服务席位（建来电、推进状态）。
- 实现能力 `call/1`：`dial` 映射到新建，建出一条外呼的振铃记录，由语音网关拨出。管理员在“管理 → 能力”里绑定后，别的应用的“拨打”才出现。
- 依赖 `party`（联系人、往来单位）与 `call`（契约）。设计见 [DESIGN](DESIGN.md)。
