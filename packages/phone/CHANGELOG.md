# Changelog

## 0.1.1

- 线路 `phone.trunk`：主管在“设置 → 线路”增删中继、改密码、号码头与固定头，可停用；网关读它并热更新。密码只有主管与网关能读。
- 来电先响联系人负责人：`receive` 记下 `preferred`，在 `widen` 之前只有他能 `take`；网关等不到他接，就经 `widen` 响给所有坐席，记录留着先响给了谁。
