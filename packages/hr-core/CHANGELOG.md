# Changelog

## 0.2.0

- 员工（`hr.employee`）改为挂在组织里的“人”上的附属对象：`extends: enterprise.element`，必填 `base` 指向一个 `ActualPerson`，一个人至多一条员工记录。姓名从人带出，不再在员工上单独填，也不再有 `account` 字段——账号由组织里的“账号登录为谁”决定。
- 自己看自己、主管看团队的范围按人判定：员工用自己登录的账号所对应的人来匹配，而不是账号本身。假期额度的所有者也改为人。
- 演示数据先在组织里建四个人并关联账号，再把员工挂上去。
- 对持有 0.1.x 数据的 preview 租户是破坏性升级：升级审阅会拒，需卸载 0.1.x 再装 0.2.0。

## 0.1.0

- 第一个版本：员工、假期额度、请假、报销；请假与报销由申请人所在单元的主管审批。考勤与补卡在下一个版本。
- 随包附带演示种子数据（`seed.yaml`，含岗位、员工、假期额度、请假与报销单及明细），首次安装自动导入，支持从侧栏一键清理演示数据。
