# call 设计

一句话定位：让任何应用都能“打一个电话”，而不认识是哪家通话供应商。

## 契约

- 只收一个动作 `dial`。挂断、转接、录音、回拨是不同供应商差异最大的部分，等第一个真实连接器落地再按它补，补的是新动作，不改 `dial`。
- `number` 是 E.164 文本；格式由实现校验，契约不收地区规则。`reference` 让实现把通话与业务记录对上，回写时用得到。
- 答复只要求 `call`：供应商给的通话编号。通话结果（接通、未接、时长）不在 `dial` 的答复里，供应商通常异步告知，留给事件 `answered`/`ended`，有入站能力后再加。

## 不做

- 不带连接器。平台的连接器现在把动作参数原样作 JSON 请求体、只支持 bearer 与 api-key：Telnyx 要 `connection_id` 等账户字段，
  Twilio 用 Basic 鉴权，阿里云、腾讯云要请求签名，都接不上。先由平台补“请求体按配置组装”与更多鉴权方式，再交付第一个真实连接器。
- 不带实现。实现是应用包 `phone`：`dial` 建一条外呼记录，由平台的语音网关经注册进来的中继拨出。
