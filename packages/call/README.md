# call

能力包：电话呼出的契约 `call/1`。

- 动作 `dial`：`number`（必填，E.164 号码）、`reference`（可选，这通电话关于哪条记录，如 `crm.activity/ACT-2026-00012`）。
- 一致性测试 `dials`：拨 `+15550100`，答复里必须有 `call`（实现给这通电话的编号）。连接器要过这条测试，管理员才能绑定。
- 用法：应用在动作上写 `uses: call/1#dial`；租户在“管理 → 能力”里绑定实现后，入口才出现。

本包只有契约，没有实现。实现以连接器的形式另外交付，见 [DESIGN](DESIGN.md)。
