# 资产

设备与其他实物资产：按类别与位置管理，领用与归还留下流转记录，维修单记结果与费用，员工可为自己领用的资产报修。

- 资产：类别、序列号、型号、供应商（往来单位）、购入日期与价格、保修到期、位置、领用人；在库 → 在用 → 在库，在库 → 已报废，有未完成维修单时不能报废。
- 流转记录：每次领用、归还由动作写一条，记人、日期与位置。
- 维修单：预防维护或故障维修，计划日、维修人、结果、费用；到期进维修人收件箱并提醒；资产汇总未完成单数与维修总费用。
- 角色：`staff` 读自己领用的资产、为它报修；`technician` 读全部、处理维修单；`custodian` 管全部与设置。

设计与取舍见 [DESIGN.md](DESIGN.md)。这是参考 ERPNext assets 与 maintenance、Snipe-IT、OFBiz assetmaint 等产品的业务思路重新设计的包，不含它们的代码与定义，以 Apache-2.0 发布。

## 安装之后

1. 在“管理 → 成员”给资产管理员授予 `custodian`，维修人员授予 `technician`，其余要领用资产的人授予 `staff`。
2. 管理员在“设置”里按自己的场地改位置、按自己的设备改类别。
3. 依赖往来单位（`party`）：供应商在往来单位里建一次，各应用共用。
