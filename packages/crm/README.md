# CRM

线索、商机、客户与联系人，以“下一步”驱动的销售管理。

- 线索：首次响应时限（默认 4 小时，超时通知负责人）、按负载自动分配、资格四问（需求、预算、时间、决策角色），一步转为商机。
- 商机：按阶段的看板，每个阶段带概率、预测类别与出阶段条件；进行中的商机必须有下一步和到期日，到期进收件箱并提醒。
- 赢单与丢单是动作：赢单写最终金额与成交日、客户变为成交客户；丢单必填原因，可记竞争对手与教训。
- 商机里的联系人各有角色（决策人、推动者、影响者、使用者、阻碍者）；产品行自动算金额与合计；加权金额随阶段变化。
- 活动（电话、会议、邮件、演示、待办）与备注可挂到线索、商机、客户或联系人；活动可在日历里看。
- 仪表盘：进行中的管道、加权预测、已赢金额、各阶段漏斗、各负责人管道、赢率、丢单原因、线索来源、每月新线索与赢单。
- 角色：`salesrep` 看本单元，`salesmanager` 看全部并管理设置。
- 客户与联系人挂在往来单位（`party`）的单位与人上：名称、网站、行业、地址、职务、邮箱、电话只在往来单位存一份，与售后、人事等应用共用。

设计与取舍见 [DESIGN.md](DESIGN.md)。这是参考 Frappe CRM 等产品的业务思路重新设计的包，不含它们的代码与定义，以 Apache-2.0 发布。

## 安装之后

1. 在“管理 → 成员”给销售授予 `salesrep`，给经理授予 `salesmanager`；经理所在的组织单元应是销售的上级。
2. 经理在“设置”里检查商机阶段的概率与出阶段条件、线索来源与丢单原因，按自己的业务改。
3. 新线索没有负责人时，自动分给进行中线索最少的销售。
