# Changelog

## 0.2.2

- 补齐包级多语言元数据与主数据角色（使用者、数据管家）简体中文译文。

## 0.2.1

- 应用改到“管理 → 主数据”里，不再在应用轨上单独占一个图标（`surface: master-data`，需要平台 0.2.9）。数据、角色与菜单不变。

## 0.2.0

- 往来单位的地址改为结构化：国家和地区（`geo.country`）、行政区划（`geo.division`，只在国家为中国时适用）、街道地址、邮政编码。依赖 `geo@^0.1.0`。
- 原来的长文本地址保留，改名为“其他地址信息”，已有的值不动。新增的字段都是可选的，0.1.0 的数据可以直接升级。

## 0.1.0

- 第一个版本：往来单位、联系人与行业，各应用共用一份，用 `extends` 挂自己的字段。
