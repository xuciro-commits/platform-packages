# 内置索引封面

本目录保存 Platform 内置产品包索引的专用市场缩略图。

- `application.production-provider.avif`：生产批次协同（内置索引）。
- `crm-index.avif`：内置 CRM，与官方市场独立的 CRM 包版本区分。

两张图片只用于界面展示，不进入声明式包制品，也不改变包版本。统一规范见 [`docs/format.md`](../../docs/format.md)。

正式市场的 listing.icon 取应用根声明，listing.cover 取包声明或包目录 assets/cover.avif。历史发行目录保留既有图标与指向发行提交的封面，不改制品摘要；没有封面则不显示。
