# 版本规则

版本号是语义版本 `主.次.补丁`。一个 `id@version` 发出后不可替换：内容变了就必须升版本。

| 改动 | 升哪一位 |
|---|---|
| 译文、文案、默认视图、README | 补丁 |
| 新增可选字段、新对象、新动作、新页面、新角色 | 次版本（`0.x` 阶段可升补丁） |
| 删字段、改字段类型、新增必填、删动作 | 主版本；平台当前拒绝这类升级，需要迁移支持后才开放 |

- 平台的升级审阅会列出字段级的增删改，不兼容的改动在审阅与提交两层被拒，并写明原因。
- CI 拒绝比已发布版本更低的版本号；每个版本在 `CHANGELOG.md` 里有自己的一节。
- 依赖范围写在 `requires`：`^1.0.0` 表示 1.x 中不低于 1.0.0 的版本。
