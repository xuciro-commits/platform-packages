# 概念

平台里的定义与规则以平台仓库的 [domain](https://github.com/xuciro-commits/platform/blob/main/docs/domain.md) 为准；这里只讲写包时要知道的。

| 概念 | 在包里是什么 |
|---|---|
| 产品包 | 唯一的交付物。一个 `id@version` 一份制品，发出后不可替换 |
| 应用 | 包声明的工作空间（`applications/`），带菜单、仪表盘与资源。一个包可以有多个，也可以没有 |
| 对象 | 业务记录的类型（`objects/<名>/object.yaml`）：字段、状态、编号、访问规则、默认视图 |
| 动作 | 唯一的写入方式（`objects/<名>/actions/`）。每个对象自带 create、edit、archive，转换与业务操作另写 |
| 页面 | 由类型生成；`page.yaml` 只在需要与生成结果不同的地方写 |
| 流程 | 条件加效果（`flows/`）：对象变化或时间到了，执行动作、发通知 |
| 角色 | 包声明的业务角色（如 `salesrep`）。安装不授予角色，管理员在“管理 → 成员”里授予 |
| 命名空间 | 包内名字的前缀。租户里已有同名项目时，安装者另起一个，包内名字整体改绑 |

包拥有定义，租户拥有记录。升级、卸载只换定义，不复制、不删除租户数据；卸载后记录保留、不可写，重装同一版本即恢复。
