# 评审清单

- [ ] 改动只在一个包里，或在 PR 描述里写明为什么要一起改。
- [ ] 版本号按 [版本规则](versioning.md) 升了；`CHANGELOG.md` 写的是用户看得到的变化。
- [ ] 新对象、动作、页面的名字在包的命名空间里；没有借用别的包的内部资源（包之间只经对象接口、动作或版本化查询）。
- [ ] 角色最小化：新动作只开给需要它的角色；没有给 `builder` 以外的角色开定义编辑。
- [ ] 每个新文案在应用的 `languages.zh-CN` 里有译文。
- [ ] 示例与样例数据里没有真实的人名、电话、邮箱或公司。
- [ ] 来源与许可：`source.relation` 如实；`redesign` 的包里没有逐个翻写来源的定义、没有来源的代码、文案与图标；
  `derived` 只来自宽松许可的来源并保留其版权声明（[来源应用](sources.md)）。
- [ ] 合入要一位非作者批准。
